# UI/UX Pro Max - Design Intelligence Skill

This is a comprehensive design system reference tool built on Anthropic's Claude Agent SDK. It provides searchable access to UI/UX design rules across multiple dimensions.

## Core Database

The skill contains:
- 84 design styles
- 192 color palettes
- 74 font pairings
- 192 product types with reasoning rules
- 98 UX guidelines
- 104 icon entries
- 16 GSAP motion presets
- 25 chart types
- Coverage across 22 technology stacks (React, Vue, Flutter, SwiftUI, Laravel, etc.)

## Primary Use Cases

Apply this skill when tasks involve visual design decisions, interaction patterns, or user experience quality control—such as designing pages, creating components, selecting color/typography systems, or reviewing accessibility and consistency.

## Priority-Based Rule Categories

The skill ranks guidance by impact:
1. **Accessibility** (Critical): contrast ratios, alt text, keyboard navigation
2. **Touch & Interaction** (Critical): minimum touch targets, spacing, feedback
3. **Performance** (High): image optimization, layout stability
4. **Style Selection** (High): visual consistency, product-type alignment
5. **Layout & Responsive** (High): mobile-first design, viewport configuration
6. **Typography & Color** (Medium): readable type sizes, semantic tokens
7. **Animation** (Medium): motion duration, reduced-motion support
8. **Forms & Feedback** (Medium): label visibility, error clarity
9. **Navigation Patterns** (High): predictable flows, deep linking
10. **Charts & Data** (Low): legends, accessible color usage

## Key Workflow

Users typically follow: analyze requirements → generate comprehensive design system → supplement with targeted searches → implement using stack-specific guidelines → validate against pre-delivery checklist.
