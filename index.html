Configuration cloud
Pour avoir un compte personnel, connecte un projet Supabase gratuit.
Comment faire (5 min)
1Crée un compte sur supabase.com (gratuit, pas de carte)
2Crée un nouveau projet — note le mot de passe
3Va dans Project Settings → API — copie l'URL et la clé anon/public
4Va dans SQL Editor et exécute ce code :
CREATE TABLE budget_data ( user_id UUID REFERENCES auth.users PRIMARY KEY, data JSONB DEFAULT '{}', updated_at TIMESTAMPTZ DEFAULT NOW() ); ALTER TABLE budget_data ENABLE ROW LEVEL SECURITY; CREATE POLICY "own" ON budget_data FOR ALL USING (auth.uid() = user_id);
5Dans Authentication → Settings, désactive "Enable email confirmations"
