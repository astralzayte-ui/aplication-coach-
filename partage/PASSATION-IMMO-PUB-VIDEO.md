## Ce qui CHANGE pour ce projet — à poser avec lui, une question à la fois

### 🟢 1. Le produit fabrique ses propres pubs

**C'est l'avantage énorme de ce projet.** Chaque vidéo générée pour un client
est une démonstration : *les photos d'avant → la vidéo d'après*.

```
le format roi     « AVANT / APRÈS » : 3 photos plates → la vidéo finie,
                  en 10 secondes. Ça se comprend sans un mot.
la source gratuite les vidéos des clients, AVEC leur accord écrit
                  (une case dans les conditions : « j'autorise
                  l'utilisation de ma vidéo pour la pub d'Immoclap »)
```

### 🟠 2. Qui est le client ? — LA question à trancher en premier

```
les agents immobiliers   ils paient tous les mois, plusieurs biens
                         → pub sur Instagram/Facebook/LinkedIn
les particuliers         un bien, une fois
                         → pub sur TikTok/Instagram
```

**Ça décide tout** : les concurrents à espionner, le prix, les réseaux, le
ton. On ne lance rien avant que ce soit choisi.

### 🔴 3. Le coût d'une vidéo — à calculer AVANT de fixer le prix

```
chaque vidéo générée consomme des crédits Higgs Field
→ prix de vente − coût Higgs − paiement − taxes = la marge
→ la marge décide combien on peut payer de pub par client
```

🔴 **Un essai gratuit sans limite peut vider le compte Higgs.** Limiter :
1 vidéo d'essai, avec filigrane, ou un e-mail vérifié obligatoire.

🟠 **À vérifier en premier** : Higgs Field propose-t-il un accès pour un
site (une API) ? À quel prix par vidéo ? Le connecteur utilisé par Claude
n'est pas la même chose qu'un branchement sur un site.

### 🔴 4. Le légal propre à ce projet

```
☐  les photos envoyées : la personne doit avoir le DROIT de les
   utiliser (case à cocher : « je suis propriétaire des photos ou
   j'ai l'autorisation »)
☐  pas de visage ni de plaque d'immatriculation dans les vidéos
   publiées sans accord
☐  la vidéo générée porte la mention « vidéo créée par IA »
   (et l'étiquette IA à chaque publication sur les réseaux)
☐  la page confidentialité nomme Higgs Field comme prestataire qui
   traite les photos, et dit combien de temps elles sont gardées
☐  une vidéo ne doit pas MENTIR sur le bien (pas de pièce inventée,
   pas de vue ajoutée) — c'est une annonce immobilière, ça engage
☐  passer le skill site-legal avant la mise en ligne
```
