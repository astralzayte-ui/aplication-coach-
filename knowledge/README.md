# Base de connaissances (vidéos assimilées)

Chaque vidéo YouTube assimilée a sa fiche ici : `knowledge/<slug-de-la-video>.md`.

## Format d'une fiche

```markdown
# <Titre de la vidéo>

- **Lien** : <url>
- **Chaîne** : <nom>
- **Assimilée le** : AAAA-MM-JJ
- **Thème** : <ex. nutrition, entraînement, marketing, produit…>

## Résumé
3 à 5 phrases.

## Points clés
- …

## À appliquer dans l'appli coach
- …

## Citations / chiffres notables
- …
```
