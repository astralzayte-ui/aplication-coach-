# Étape 1 — Créer les outils (une seule fois)

## A. Google Form (3 min)
1. Ouvrir le script : https://docs.google.com/document/d/1nrrg2jyN_mKa11slFQUsyqm1ZljpZ-aFhdAh8NLksvk/edit
2. Sélectionner tout le code sous « CODE À COPIER » (de `/**` jusqu'au dernier `}`) → Copier.
3. Ouvrir https://script.google.com/home/projects/create (compte astralzayte@gmail.com).
4. Effacer `function myFunction() {}` → Coller.
5. Cliquer 💾 (Enregistrer).
6. Vérifier que la liste en haut affiche `creerFormulaireSahir` → cliquer ▶ Exécuter.
7. « Autorisation requise » → Examiner les autorisations → choisir astralzayte@gmail.com
   → Paramètres avancés → Accéder à Projet sans titre (non sécurisé) → Autoriser.
8. En bas, Journal d'exécution : copier la ligne « ✅ LIEN À ENVOYER AUX CLIENTS ».
9. Envoyer ce lien à Claude.

## B. Meta Business (5 min)
1. https://business.facebook.com/overview → Créer un compte.
2. Nom de l'entreprise : Sahir Digital · ton nom · e-mail pro → Envoyer.
3. Confirmer l'e-mail reçu.

## C. Cloudflare (2 min)
1. https://dash.cloudflare.com/sign-up → e-mail + mot de passe → Créer.
2. Confirmer l'e-mail. Choisir l'offre Free si demandé.

## D. Clé Gemini (2 min)
1. https://aistudio.google.com/apikey (compte Google).
2. « Create API key » → « Create API key in new project ».
3. Copier la clé et la garder dans une note privée. NE PAS l'envoyer à Claude.

## E. Buffer (2 min)
1. https://login.buffer.com/signup → offre Free.
2. Ne connecter aucun réseau pour l'instant.
