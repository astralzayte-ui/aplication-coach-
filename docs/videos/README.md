## Fil rouge commun
- **Méthode en étapes** : recherche produit/niche (Trendtrack, Kalodata, PipiAds, SEMrush > 10-15k recherches/mois, Google Trends, commentaires TikTok, Google Forms) → sourcing (agent privé, Alibaba/1688, groupes Facebook) → branding premium (Figma/Canva, Shopify, ThemeForest) → acquisition.
- **ICP par IA** : Claude + Trendtrack (10 concurrents FR/US) + Claude in Chrome pour scraper les avis Trustpilot/Amazon/Reddit → fiche ICP Notion.
- **Contenu** : 2 vidéos courtes/jour cross-postées (TikTok, Shorts, Reels) + stories ; répartition 50 % TOFU / 30 % MOFU / 20 % BOFU ; script Hook 0-5 s → intrigue → valeur → climax → CTA ; 10 angles universels.
- **Conversion** : profil Instagram optimisé (Big Idea, promesse en une ligne, CTA, highlights, 3 posts épinglés) ; setting/closing en DM (20-50 messages/jour, 20-30 % du CA).
- **Site qui convertit** : preuves sociales/avant-après, réassurance, garantie, sticky add-to-cart, prix par jour, upsell/OTO, quiz funnel, barre de progression cadeau.
- **Influence** : micro-influenceurs 5k-50k, gifting + 20-30 % de commission via UpPromote, puis meilleurs contenus relancés en Meta Ads.
- **Chiffres** : marges 35-50 % en organique vs 10-15 % en ads ; panier moyen 40-200 € ; 0-200 € de budget de départ.
- **Valeur n°1 d'un accompagnement (témoignage Kamila)** : humain, suivi personnalisé, réactivité.
